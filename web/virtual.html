M8 Virtual Teensy

A complete M8 tracker running in your browser — no Teensy required. Sequencer, instruments, effects and sampler are emulated in WebAssembly; songs and samples persist in your browser.

Arrow keys move. Left Shift = Shift, Space = Play, Z = Option, X = Edit (remap with the Map button). A–' play notes, -/= octave, [/] velocity.

Shift+arrows switch views (Song, Chain, Phrase, Instrument, Mixer, ...). Press Play on the demo song to hear it. FILE view saves/loads songs, imports samples and bounces the master to WAV.

Frontend display code from M8WebDisplay (MIT). Virtual firmware is original work inspired by the M8 workflow.
